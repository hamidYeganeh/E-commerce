# وضعیت امکانات درخواستی

دامنهٔ کار، تمام فهرست کاربر است. امکانات داخلی زیر پیاده و در محیط محلی بررسی شده‌اند؛ اتصال خارجی صرفاً با فرم تنظیمات «متصل» محسوب نمی‌شود.

| بخش | پیاده‌سازی و محل استفاده |
| --- | --- |
| سفارش | طبقه‌بندی، جست‌وجو، فهرست و جزئیات، گردش وضعیت مجاز، تماس با خریدار، چاپ فاکتور و گیرنده، بسته‌بندی و ارسال و رهگیری؛ `/admin/orders` |
| کاتالوگ | برند، دستهٔ سلسله‌مراتبی، تگ، مشخصات فنی، تنوع و قیمت، ورود/ویرایش و اعتبارسنجی انتشار؛ پنل کاتالوگ |
| ویرایش گروهی | تغییر دسته/برند/وضعیت، فهرست کم‌موجودی، خروجی قیمت اکسل، پیش‌نمایش و اعمال اتمیک با کنترل نسخه؛ `/admin/bulk` و میز موجودی |
| محتوای محصول | ویدیو و صوت با URL معتبر، پرسش‌وپاسخ با تأیید مدیر، محصولات و مقالات مرتبط، بنر میان محصولات |
| SEO | عنوان و توضیحات و انتشار دسته/تگ/محصول/مقاله/صفحه، بررسی محتوای SEO، sitemap، robots و دادهٔ ساختاریافته؛ `/admin/seo` |
| ارسال | روش‌های متعدد، هزینهٔ ثابت/وزنی/درصد مبلغ، آستانهٔ رایگان، محدودهٔ استان/شهر و وزن؛ انتخاب و محاسبه مجدد روی سرور در تسویه |
| گزارش | فروش روزانه و سالانه، تعداد سفارش و اقلام، میانگین اقلام، ثبت‌نام، گروه‌های پرفروش، مشتریان وفادار، بازدید محصول/مقاله و سبدهای رهاشده؛ `/admin/reports` |
| پیش‌بینی | برآورد هفت‌روزه از میانگین سی روز گذشته، تنها با حداقل چهارده روز سابقه؛ روش و محدودیت در گزارش مشخص است |
| وبلاگ | مدیریت مقاله، انتشار، صفحهٔ فهرست/جزئیات، SEO، ارتباط مقاله و محصول؛ `/blog` |
| کلمات کلیدی | صفحهٔ مستقل تگ، محصولات مرتبط، SEO، FAQ، دیدگاه با نظارت مدیر |
| لید | فرم مشاوره در محصول/دسته/تگ، رضایت مجزا برای تبلیغات، میز مدیریت وضعیت و یادداشت |
| تنظیمات | لوگو، favicon، تماس، شبکه‌های اجتماعی، منو، صفحات قابل ویرایش، شمارهٔ سفارش‌گیرندهٔ خصوصی، پرسش‌های امتیاز سفارش، ردیف محصولات خانه و بنر |
| حساب | ورود/عضویت موبایلی OTP، سوابق، رهگیری، تنظیم رضایت پیامکی و تاریخچهٔ کیف پول |
| موجودشدن کالا | ثبت درخواست برای تنوع ناموجود، فهرست مدیریت و اعلان بعد از موجودشدن؛ هر چرخه یک اعلان |
| مشتریان | جست‌وجو، ثبت دستی بدون ادعای تأیید موبایل، سوابق و آخرین خرید، خروجی اکسل، اعتباردهی/کسر کنترل‌شدهٔ کیف پول |
| تخفیف | ثابت/درصدی، سقف، حداقل خرید، تاریخ و محدودیت استفاده؛ رزرو سهمیه در پرداخت و آزادسازی در شکست قطعی؛ تسویهٔ صفر بدون درخواست بانکی |
| سبد | ذخیرهٔ سرور برای مهمان و مشتری، ادغام یک‌باره هنگام ورود، جداسازی حساب‌ها، آمار و فهرست سبد رهاشده |
| اعلان | پس از ثبت، پرداخت موفق، تأیید فروشگاه، ارسال، افزایش اعتبار، دو ساعت رهاشدن، پنج روز پس از ارسال، موجودی، مشتری غیرفعال، سفارش جدید و آمادهٔ ارسال برای مدیر |
| درگاه | مدیریت و انتخاب چند تنظیم زرین‌پال، اسرار در محیط سرور، تأیید سمت سرور و تطبیق پرداخت نامشخص با تنظیمات همان تراکنش |

مدیریت عملیاتی از `/admin/operations` و میزهای مرتبط قابل دسترسی است. تمام دسترسی‌های مدیریت بر اساس مجوز واقعی کارکنان و ورود دومرحله‌ای کنترل می‌شوند. رابط‌های جدید از اجزای shadcn استفاده می‌کنند.

## اجرای اعلان‌ها

Worker مستقل لازم است. یازده قالب اولیه به صورت پیش‌نویس و غیرفعال seed می‌شوند. زمان‌بندی محدود، جلوگیری از ثبت تکراری، بررسی دوبارهٔ وضعیت جاری سبد/سفارش/موجودی/رضایت، و نگهداری نتیجهٔ نامشخص برای بررسی دستی پیاده شده است. فعال‌کردن یک قاعده به تنهایی جای حساب پیامکی را نمی‌گیرد. رضایت تبلیغاتی پیش‌فرض فعال نیست. کیف پول فعلاً دفتر اعتبار کنترل‌شدهٔ مدیر است؛ شارژ بانکی مستقل و پرداخت سفارش از کیف پول در این کار ادعا نشده است.

## اتصال‌های خارجی: وضعیت واقعی

| سرویس | وضعیت |
| --- | --- |
| زرین‌پال | درخواست، تأیید، بازیابی و تطبیق پیاده و با provider آزمایشی بررسی شده؛ اجرای واقعی نیازمند Merchant ID و فعال‌سازی است |
| کاوه‌نگار | OTP و پیامک عملیاتی پیاده؛ نیازمند API key، خط و قالب معتبر |
| ملی پیامک | adapter پیامک عملیاتی طبق قرارداد HTTPS کلاسیک؛ نیازمند نام کاربری/رمز وب‌سرویس/خط؛ تأیید زنده انجام نشده |
| ترب | API v3 دریافت محصولات و کنترل امضای درخواست؛ نیازمند ثبت و تأیید فروشگاه در ترب |
| گفتینو | ابزارک با شناسهٔ عمومی پنل؛ در صفحات حساس حساب و خرید نمایش داده نمی‌شود؛ نیازمند حساب |
| باران و محک | اتصال واقعی پیاده نشده؛ نسخهٔ نرم‌افزار و قرارداد API مشخص نیست و کاربر حساب/کلید ندارد |
| تاپین و روناد | اتصال واقعی ثبت مرسوله/انبار پیاده نشده؛ حساب عملیاتی و قرارداد سرویس در اختیار نیست |
| رایچت و یکتانت | کد نصب اختصاصی حساب موجود نیست؛ اتصال فعال و رهگیری واقعی پیاده نشده |
| ایمالز و ذره‌بین | نیازمند ثبت و تأیید سایت و تعیین شیوهٔ دریافت اطلاعات؛ اتصال تأییدشده موجود نیست |

در `/admin/integrations` کاربرد، نیازمندی و وضعیت این سرویس‌ها توضیح داده شده است. موارد بدون قرارداد قابل فعال‌سازی صوری نیستند. فروشگاه برای استفاده از امکانات داخلی به خرید همهٔ این سرویس‌ها نیاز ندارد.

## محدودهٔ بررسی

آزمون‌های محلی از بانک و پیامک آزمایشی استفاده می‌کنند؛ ادعای ارسال واقعی یا تأیید حساب سرویس بیرونی ندارند. فیلم/صوت به صورت لینک و پخش‌کننده است، بدون تبدیل فرمت در سرور. بررسی SEO، ابزار تشخیص است و تضمین رتبهٔ جست‌وجو نیست. صفحات محتوا از متن امن استفاده می‌کنند. فهرست‌ها و خروجی‌های بزرگ صفحه‌بندی/دسته‌بندی می‌شوند و تغییر اکسل قبل از ثبت باید پیش‌نمایش شود.
