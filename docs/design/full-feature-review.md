# بررسی پیاده‌سازی کامل فروشگاه

بررسی بر کد فعلی انجام شد؛ مبنای کاربر، source موجود و تغییرات commit‌نشده بود. این سند نتیجهٔ مرور کد و تست محلی است، نه گواهی اسکن خارجی یا استقرار production.

## اصلاحات بررسی مستقل

- ZIP اکسل: کنترل واقعی اندازهٔ بازشده، شمار و مرز دقیق ورودی‌ها، تطابق local/central، جلوگیری از مسیر نامعتبر، فرمول و فایل بیش‌ازحد؛ regression برای EOCD دست‌کاری‌شده اضافه شد.
- سبد: فضای ذخیرهٔ مجزا برای هر مالک، hydration از سرور و ادغام مهمان بدون دوبرابرکردن اقلام؛ کنترل دسترسی و انتقال مالک در integration بررسی شد.
- اعلان‌های قدیمی: قبل از ارسال، نسخه/فعالیت سبد، خرید جدید، رضایت و موجودی فعلی دوباره کنترل می‌شوند. نتیجهٔ نامشخص خودکار تکرار نمی‌شود.
- سبد رهاشده: یک شرط SQL مشترک قبل از count و pagination در گزارش و میز مدیریت استفاده می‌شود.
- سفارش رایگان: مبلغ صفر با تخفیف معتبر بدون تماس به درگاه تسویه می‌شود؛ مبلغ مثبت همچنان درگاه معتبر می‌خواهد.
- فهرست‌های مدیریت: جست‌وجو و صفحه‌بندی رکوردها/تخفیف‌ها و batchهای اکسل مانع پنهان‌شدن داده‌های قدیمی می‌شود.
- امتیاز سفارش: پرسش‌های تنظیم‌شده واقعاً در حساب مشتری نمایش و سمت سرور تطبیق داده می‌شوند.

دو بازبین مستقل، اصلاح یافته‌های محدودهٔ خود را با بررسی source و تست‌های متمرکز تأیید کردند. این بررسی، جای تست زندهٔ providerهای بیرونی را نمی‌گیرد.

## شواهد محلی

- ۱۵ تست واحد و ۹۰ تست integration موفق: پوشش مجوز، CMS، ارسال، تخفیف، پرداخت صفر، کیف پول، سبد، ZIP/اکسل، اعلان، ترب، گزارش و گردش سفارش.
- ۱۰ تست احراز هویت و یک تست واقعی صف با Redis و worker نیز موفق شدند؛ مجموع آزمون‌ها ۱۱۶ مورد است.
- HTTP smoke با کاربر موقت دارای MFA: سیزده مسیر اصلی مدیریت و فروشگاه، پاسخ ۲۰۰ و محتوای مورد انتظار؛ کاربر آزمایش پس از بررسی حذف شد.
- TypeScript، ESLint و build تولید موفق بودند؛ نتیجهٔ آخرین اجرای محلی در `.data/final-*.log` ثبت شده است.
- `npm audit --omit=dev` هیچ آسیب‌پذیری گزارش نکرد. وابستگی‌های توسعه جداگانه هستند؛ هیچ downgrade عمده برای خاموش‌کردن گزارش اعمال نشده است.
- اتصال PostgreSQL و هر دو Redis و پردازش ping توسط worker محلی تأیید شد.
- بررسی تصویری نهایی به علت timeout ابزار مرورگر کامل نشد؛ smoke HTTP جای آن محسوب نمی‌شود.
- seed افزایشی است؛ دادهٔ محصول، قیمت و موجودی موجود را بازنویسی نمی‌کند.

ارسال پیامک واقعی، پرداخت واقعی و اتصال حسابداری/لجستیک بیرونی بررسی زنده نشده‌اند. شرح دقیق در [وضعیت امکانات](../full-feature-implementation.md) آمده است.
